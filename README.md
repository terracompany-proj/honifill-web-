## About

Honifill makes lightweight, high-strength paper honeycomb products for industries that need protective, sustainable packaging and structural materials. The products are made from kraft paper and water-based adhesives, so they are recyclable, biodegradable and plastic-free. They are positioned as eco-friendly alternatives to wood, plastic and thermocol (EPS).

> *Hexagon Power. Human Innovation.*

This repository contains the source code for the Honifill website, which presents the product range, industries served, company background and enquiry details.

## Getting Started

### Run locally

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```
2. Open `index.html` in your browser, **or** serve it with a local server:
   ```bash
   # Python
   python -m http.server 8000

   # or Node
   npx serve .
   ```
3. Visit `http://localhost:8000`

## Deployment

The site is a static website and can be hosted on any static host (GitHub Pages, Netlify, Vercel, or traditional shared hosting). Deploy by uploading the project files to the web root of the host.
